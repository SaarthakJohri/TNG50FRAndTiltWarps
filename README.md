Hello! This repository contains the data products and analysis for a paper investigating the connections between dark matter halo figure rotation and tilt to the warp of stellar disks currently in prep! Most of the notebooks are written for use with the IllustrisTNG JupyterLab server, where you can call on the simulation data directly. PaperFigures is re-written to work with data on my local machine, so its directories will need to be re-written to work either in TNG JupyterLab or your machine. This repo folder is the one I've been working in since moving to my local machine, so there shouldn't be any issues if you clone the whole thing, but please email me at sjohri@umich.edu if there are any issues!
